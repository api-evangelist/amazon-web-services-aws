# Amazon Web Services (AWS) GraphQL API

AWS AppSync creates serverless GraphQL and Pub/Sub APIs that simplify application development through a single endpoint for data querying, updating, and publishing.

**Endpoint:** https://appsync.amazonaws.com

**Documentation:** https://aws.amazon.com/appsync/

**References:**

- Documentation: https://docs.aws.amazon.com/appsync/
- GettingStarted: https://docs.aws.amazon.com/appsync/latest/devguide/welcome.html
